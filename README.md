# kilko.de

My homepage and public feed of everything: blog posts, reviews, links, talks, plus imported activity from Mastodon, Bluesky, GitHub, BookWyrm, and Letterboxd.

## Stack

- [Zola](https://www.getzola.org/)
- Deno scripts import external activity into `content/feed/` (state lives in `data/`).
- GitHub Actions builds and deploys to GitHub Pages. `import.yml` refreshes imports every 6 hours and commits any changes.

## Development

```sh
direnv allow   # or: nix develop — provides zola + deno
zola serve
deno task test
```

## Content

Everything under `content/feed/` is one chronological timeline at `/feed`; each subdirectory is a category with its own page and Atom feed (e.g. `/feed/links/`, `/feed/links/atom.xml`).

- `posts/`, `reviews/`, `links/`, `talks/` are authored by hand: `deno task new <post|review|link|talk> "Title"`.
- `mastodon/`, `bluesky/`, `github/`, `books/`, `movies/` are generated by `deno task import`.

## Feeds

- `/feed/atom.xml` — everything
- `/feed/<category>/atom.xml` — per category
- `/tags/<tag>/atom.xml` — per tag
- `/original.atom.xml` — authored content only (posts, reviews, links, talks)
